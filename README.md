# 🎬 MadaMovie — Front-end

Application mobile et web de streaming et gestion de films malgaches, développée avec Angular et Ionic.

## 🚀 Stack technique
- **Framework** : Angular + Ionic
- **Langage** : TypeScript
- **Mobile** : Capacitor (iOS & Android)
- **Auth** : Guards JWT
- **CI/CD** : GitHub Actions

## ✨ Fonctionnalités
- Authentification et inscription utilisateur
- Catalogue de films avec système dabonnement
- Gestion des bouquets et abonnements
- Interface responsive mobile-first

## 🔗 Back-end
Voir le repo [back-end-mada-movie](https://github.com/HardyRak/back-end-mada-movie) — Spring Boot + JWT

## ▶️ Lancer le projet
```bash
npm install
ionic serve
```
