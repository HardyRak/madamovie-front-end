# 🎬 MadaMovie — Front-end

Application mobile et web de streaming de films malgaches, développée avec Angular et Ionic.

[![Angular](https://img.shields.io/badge/Angular-DD0031?style=flat&logo=angular&logoColor=white)](https://angular.io)
[![Ionic](https://img.shields.io/badge/Ionic-3880FF?style=flat&logo=ionic&logoColor=white)](https://ionicframework.com)
[![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=flat&logo=typescript&logoColor=white)](https://typescriptlang.org)

## 🚀 Stack technique
- **Framework** : Angular + Ionic (mobile-first)
- **Langage** : TypeScript
- **Mobile** : Capacitor (iOS & Android)
- **Auth** : Guards JWT
- **CI/CD** : GitHub Actions

## ✨ Fonctionnalités
- Authentification et inscription utilisateur (JWT)
- Catalogue de films avec système d'abonnements
- Gestion des bouquets et abonnements
- Interface responsive mobile-first

## 🔗 Back-end
Voir le repo [back-end-mada-movie](https://github.com/HardyRak/back-end-mada-movie) — Spring Boot + JWT

## ▶️ Lancer le projet
```bash
npm install
ionic serve
```
